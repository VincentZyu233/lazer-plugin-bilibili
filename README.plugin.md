# 哔哩哔哩（Lazer Lua 插件）

把 B 站当作曲库：搜索、播放、歌词、收藏夹、排行榜、热门、相关推荐、UP 主投稿、评论、扫码 / Cookie 登录。

运行于 Lazer 的 Lua 插件宿主（v2.0.210 实测，仅使用该版本提供的 14 个 host API）。

## 安装

1. 下载 `community.bilibili.music.zip`（不要解压改目录结构，ZIP 根目录必须是 `manifest.json`）。
2. Lazer → 插件管理 → 导入 ZIP 插件 → 选择该 ZIP。
3. 列表出现「哔哩哔哩」并处于启用状态即可；首次联网会请求网络授权，需要允许。

## 登录

两种方式，任选其一：

- **扫码**（推荐）：插件登录框点扫码 → 用哔哩哔哩 App 扫二维码 → 在 App 里确认。扫码成功后自动下发并保存登录态，无需手动复制 Cookie。
- **Cookie**（兜底）：浏览器登录 `www.bilibili.com`，从开发者工具复制完整 Cookie（必须含 `SESSDATA` 与 `bili_jct`），粘贴到插件的 Cookie 登录框。

> 扫码若提示「不支持的二维码」：`qrcode_key` 有时效，先**重新打开登录页生成新码**，不要复用旧码；反复失败再用 Cookie 登录兜底。

## 能力

- 搜索（WBI 签名）、单曲详情、音频流（自动选最高音质，可指定 `original`/`flac`）
- 歌词（B 站站内 `ai-zh` 字幕为主源，返回逐行时间轴由宿主合成；lrclib 仅作兜底）
- 首页热门、全站排行、相关推荐、UP 主投稿、评论
- 登录后：本人收藏夹、默认收藏夹喜欢列表、加/取消喜欢

## 已知限制

- 只取音频流（`m4s`），不含视频画面；音质通过 `quality` 参数选择，不提供设置页（v2.0.210 无该扩展点）。
- 歌词取 B 站视频自带的 `ai-zh` 字幕（与视频同源、时间轴零误差），需要登录态；无字幕的视频才会去 lrclib 按标题找对应曲库歌词，对不上时长时宁可返回无歌词。8 小时以上的合集只取前 1200 行。
- 歌词主源与 UP 主页投稿都需要登录态；匿名时歌词显示「歌词暂时无法加载」、UP 主页提示登录。
- UP 主页投稿与收藏夹在插件内自动翻页，首次打开可能需要数秒，之后走宿主缓存。
- 高频访问可能触发 B 站风控（`-412`）；遇到时稍后重试，插件不会自动重试。
- 搜索页仍是 4 个 tab，其中专辑 / 歌单为空——B 站没有对应的「专辑」层，收成 2 tab 需要改宿主 UI，超出插件能力。

## 隐私

Cookie / SESSDATA 仅保存在本插件的 `lua_plugin_data` 存储沙箱，用于维持登录态；不会随错误信息外泄——所有操作失败只返回状态码，不含响应正文、Cookie 或签名 URL。
