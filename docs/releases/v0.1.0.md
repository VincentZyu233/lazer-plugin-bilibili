# v0.1.0

首个公开版本。把 B 站当作曲库，跑在 Lazer 的隔离 Lua 插件沙箱里。

### 能力

1. **扫码 / Cookie 双登录**
   - 扫码链路完整：`qrKey` → `qrUrl` → `qrCheck`，`poll` 返回 `code=0` 时响应头的 `Set-Cookie` 会下发全套登录态，插件自动吸收并持久化。
   - `qrUrl` 返回**纯 URL 字符串**而不是 Lua table —— 发行版宿主把 table 桥接成非 Map 对象后会走 `toString()`，那样渲染出来的二维码 B 站 App 判为废码。
   - Cookie 粘贴作为兜底，必须含 `SESSDATA` 与 `bili_jct`。

2. **WBI 签名搜索**
   - `w_rid = md5(query + salt)`，salt 由 `nav` 的 `wbi_img` / `sub_url` 文件名拼接后按 MIX 表取前 32 位。
   - `/x/space/wbi/arc/search` 强制要求 `wts`，缺失必返 `412`；统一注入 `host.now()` 毫秒值。

3. **音频流**
   - `playurl` 自动选最高音质，支持 `original` / `flac`。
   - 每路响应都带 `Referer: https://www.bilibili.com/`；裸请求实测必 403。

4. **歌词：站内字幕为主源**
   - 三步链路 `view` → `player/wbi/v2` → 字幕 CDN JSON，取视频自带的 `ai-zh` 字幕，与视频同源、时间轴零误差。
   - 只返回逐行 `lines[]`（`{text, startMs}`），时间轴交宿主合成——在 Lua 里拼 LRC 会在两千多行时撞上 250 000 指令预算的 `408`。
   - 字幕行数闸门 1200 行（清洗后上限的 3 倍余量）；8 小时合集截断不报错。
   - `lrclib` 降级为兜底，带时长闸门：对不上宁可返回无歌词，不硬凑。

5. **发现与收藏**
   - 首页热门、全站排行、相关推荐、UP 主投稿、评论区。
   - 收藏夹列表 / 夹内曲目 / 红心同步；夹子自身无封面时回退第一个视频的封面，避免灰色占位符。
   - 分页聚合器保证宿主问 100 行就给 100 行（实测 684 条投稿 8 次调用读全）。

6. **错误归一**
   - `-101 / -400 / 401 / 301 / 302 → code 40 / HTTP 401`
   - `-352 → 40 → 401`（提示需要登录）、`-412/412 → 429`（风控限流）。
   - 未知 op 返回结构化 `error`，不崩、不影响已加载的列表。
   - 所有失败只回状态码，不含响应正文、Cookie 或签名 URL。

### 宿主兼容性

- 实测宿主：Lazer v2.0.210（Windows x64）。
- 仅使用该版本提供的 14 个 host API，向上兼容更新版本。
- 插件包 12 个文件、约 22 KB，纯 Lua，无原生依赖。

### 已知限制

- 只取音频流（`m4s`），不含视频画面。
- 歌词主源与 UP 投稿需要登录态；匿名时歌词不可用、UP 主页提示登录。
- 搜索页仍是 4 个 tab，专辑 / 歌单为空（B 站无对应数据层，收成 2 tab 需改宿主 UI）。
- 高频访问触发 `-412` 时不自动重试。

### 验证

- 离线契约测试 20/20 全绿（WBI 签名、`lines[]` 歌词、扫码纯 URL、双桶搜索、100 行聚合、`length→durationMs`、`-352/-412` 映射、封面回退、指令预算门、未知 op）。
- 真机 GUI 走通：扫码登录、搜索起播、歌词显示、收藏夹封面、UP 投稿时长、评论正文。
